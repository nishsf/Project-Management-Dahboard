# 📊 Project Management Dashboard

An interactive **Power BI dashboard** designed to provide a comprehensive overview of project performance, financial outcomes, project timelines, and operational details.

## 📌 Project Overview

This project analyzes **99 projects** across different regions, departments, project types, managers, complexity levels, statuses, and project phases.

The dashboard transforms project data into an interactive reporting solution that allows users to monitor project performance, compare project characteristics, and explore detailed project-level information.

---

## 🎯 Objectives

The main objectives of this dashboard are to:

- Monitor overall project performance
- Analyze project costs and benefits
- Evaluate project profitability using the Benefit-Cost Ratio
- Track project distribution across regions and departments
- Monitor project status and completion
- Analyze project trends over time
- Visualize project timelines and phases
- Provide detailed project-level information for further analysis

## 🔍 Key Insights

Based on the dashboard:

- The portfolio contains **99 projects** with a total project cost of approximately **$412M**.
- The projects generate approximately **$874M in benefits**, resulting in an overall **Benefit-Cost Ratio of 2.12**.
- Project volume decreased from **27 projects in 2022** to **17 in 2023**, followed by **16 projects in both 2024 and 2025**.
- Projects are distributed across four regions: **North, West, South, and East**.
- Project statuses include **Completed, Cancelled, In-Progress, and On-Hold**.
- Projects are categorized into **Low, Medium, and High complexity** levels.
- The dashboard tracks projects across five phases: **Explore, Develop, Plan, Implement, and Measure**.
